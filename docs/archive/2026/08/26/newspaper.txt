* Unicode String Operations Expose Hidden Logic and Security Pitfalls
  https://sethmlarson.dev/when-str-lower-is-a-security-vulnerability
  Treating domain-specific protocol identifiers (like DNS names or TLS SANs) as human-readable Unicode text causes severe implementation vulnerabilities. Because Unicode case folding can alter string lengths, mapping rules, and codepoint behaviors across versions, basic operations like str.lower() or str.upper() lead to subtle exploits, unexpected data mutations, and protocol mismatches. Quote: This idiocy is a big part of why it was so important to get Python people working on TLS implementations to understand that the defined mechanism for SANs... says that these are DNS names, they specifically are not to be understood as some sort of human readable text
